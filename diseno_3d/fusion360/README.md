# Archivos de Fusion 360

| Archivo | Descripción |
|---|---|
| `Encapsulado_Agua_Clara_v01.f3d` | Versión inicial (Avance #2) |
| `Agua clara Case final.f3d` | Case final (Avance #3): caja inferior y tapa superior independientes |

**Cómo abrir:** Autodesk Fusion → *File > Open* → *Open from my computer* → seleccionar el `.f3d`.

Para imprimir: exportar cada cuerpo como STL (*File > 3D Print* o clic derecho sobre el cuerpo → *Save as Mesh*) e imprimir en PLA.
